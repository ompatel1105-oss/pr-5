# 📘 README.md

## 🧠 Project Title
Student Performance Analysis using Linear Algebra & Machine Learning

---

## 📌 Project Description
This project is based on analyzing student marks using mathematical concepts and data science techniques. The dataset contains marks of students in subjects like Math, Physics, Chemistry, English, and Computer Science.

Instead of simple analysis, this project converts the data into vectors and matrices, and then applies linear algebra operations to understand relationships, similarity, and patterns in the data.

---

## 🎯 Objective
- Convert student data into vector form
- Apply mathematical operations to analyze performance
- Understand similarity between students
- Perform dimensionality reduction using PCA and LDA
- Visualize high-dimensional data in 2D

---

## ⚙️ Tools & Libraries Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

---

## 🔍 Steps Performed

### 1. Data Loading
- Dataset loaded using Pandas
- Preview using head()

### 2. Vector Conversion
- Each student converted into a numerical vector

### 3. Norm Calculation
- L1 Norm → total performance
- L2 Norm → magnitude of performance

### 4. Similarity Analysis
- Dot product used to measure similarity
- Angle between vectors calculated

### 5. Cross Product
- Used on 3D subset of data to understand orthogonality

### 6. Matrix Operations
- Transpose of matrix
- Matrix multiplication

### 7. Determinant & Inverse
- Determinant used to check matrix properties
- Inverse used for reversing transformation

### 8. Eigenvalues
- Shows important directions in data

### 9. LU Decomposition
- Matrix broken into lower and upper triangular matrices

### 10. SVD (Singular Value Decomposition)
- Matrix decomposed into simpler components

### 11. PCA (Principal Component Analysis)
- Reduced 5D data into 2D
- Used for visualization

### 12. LDA (Linear Discriminant Analysis)
- Focused on separating data
- Used for classification understanding

---

## 📊 Output
- Vector calculations (Norms, Dot, Cross)
- Matrix operations results
- Eigenvalues & SVD values
- PCA scatter plot
- LDA projection graph
